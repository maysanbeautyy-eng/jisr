# جسر: مترجم صوتي عراقي ⇄ فارسي

تطبيق ويب يتثبّت على شاشة الآيفون. كل شخص يلبس سماعة واحدة، والترجمة تُنطق في أذن الطرف الثاني.

## النشر على الآيفون (مرة وحدة)

1. فك ضغط الملف من تطبيق «الملفات».
2. افتح github.com من Safari وسجّل حساب مجاني.
3. أنشئ مستودع جديد (New repository) باسم `jisr` وخليه Public.
4. اختر Add file ثم Upload files وارفع **الملفات** كلها (مو المجلد): `index.html` و `sw.js` و `manifest.webmanifest` والأيقونات الثلاث. ثم اضغط Commit.
5. من Settings ثم Pages: اختر Branch = main وFolder = root ثم Save.
6. بعد دقيقة أو دقيقتين يطلع الرابط: `https://اسم-حسابك.github.io/jisr/`
7. افتح الرابط في Safari، اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية».
8. افتح التطبيق مرة وحدة وأنت متصل بالإنترنت حتى تتخزّن الواجهة، وبعدها يفتح بدون إنترنت.

## الإعداد

- اربط FreeBuds Flip بالبلوتوث، وفي التطبيق اضغط **اختبار الأذنين**. أول نغمة للعراقي وثاني نغمة للفارسي. إذا الجهة معكوسة اضغط «بدّل الأذنين».
- من الإعدادات (⚙) حط مفتاح **Claude API** للحصول على أفضل ترجمة للهجة العراقية. بدون مفتاح يستخدم ترجمة مجانية جودتها أضعف.
- لتوجيه الصوت لأذن واحدة حط مفتاح **OpenAI** واختر «OpenAI» في خيار الصوت. صوت الجهاز الجاهز يطلع بالأذنين الاثنتين، وما أقدر أوجّهه.

## شنو يشتغل أوفلاين وشنو لا

| الميزة | بدون إنترنت |
|---|---|
| فتح التطبيق | يشتغل |
| العبارات الجاهزة (26 عبارة) | تترجم وتنطق بصوت الجهاز |
| الترجمة الحرة (Claude أو المجانية) | تحتاج إنترنت |
| التعرف على الكلام من المايك | غالباً يحتاج إنترنت على الآيفون |
| صوت OpenAI الموجّه للأذن | يحتاج إنترنت |

## ملاحظات

- الآيفون ما عنده صوت فارسي جاهز، فللنطق الفارسي استخدم صوت OpenAI.
- المفاتيح تنحفظ في الجوال فقط. استخدم مفاتيح بحد صرف محدد.
- إذا السماعة تستخدم مايكها أثناء الكلام قد ينزل مستوى جودة الصوت. هذا سلوك بلوتوث طبيعي.
