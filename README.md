# جسر: مترجم صوتي مباشر عراقي ⇄ فارسي

تطبيق ويب يتثبّت على شاشة الجوال. كل شخص يلبس سماعة واحدة، والترجمة تُنطق في أذن الطرف الثاني.

الرابط: https://maysanbeautyy-eng.github.io/jisr/

## التثبيت على الآيفون

1. افتح الرابط من Safari.
2. اضغط زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».
3. افتح التطبيق مرة وأنت متصل بالإنترنت حتى تتخزّن الواجهة.

## الاستخدام

1. اربط السماعة، واضغط **اختبار الأذنين**. أول نغمة للعراقي والثانية للفارسي. إذا الجهة معكوسة اضغط «بدّل الأذنين».
2. اضغط زر لغتك وتكلّم. كل جملة تنترجم وتنطق في أذن الطرف الثاني، ثم يتحول الدور له تلقائياً.
3. اضغط الزر مرة ثانية للإيقاف.

الشريط العلوي يبيّن حالة الترجمة والصوت والمايك. اضغط أي واحد منها حتى يفتح إعداده.

## المفاتيح (من الإعدادات)

| المفتاح | شنو يضيف | بدونه |
|---|---|---|
| Claude API | ترجمة دقيقة للهجة العراقية، مع فهم سياق المحادثة | ترجمة مجانية أضعف |
| OpenAI API | صوت موجّه لأذن واحدة، صوت فارسي، تعرف أدق على الكلام، تنزيل الأصوات | صوت الجهاز في الأذنين، وبدون فارسي على الآيفون |

زر «اختبر» جنب كل مفتاح يتأكد منه قبل الحفظ. المفاتيح تنحفظ في الجوال فقط.

## بدون إنترنت

| الميزة | بدون إنترنت |
|---|---|
| فتح التطبيق | يشتغل |
| 75 عبارة جاهزة في 8 أقسام | تترجم دائماً |
| نطق العبارات في الأذن الصحيحة | يشتغل بعد «نزّل الأصوات» من تبويب العبارات (يحتاج مفتاح OpenAI مرة وحدة) |
| جمل تُرجمت قبل | تترجم من الذاكرة، وتنطق إذا انحفظ صوتها |
| ترجمة جملة جديدة | تحتاج إنترنت |
| التعرف على الكلام من المايك | يحتاج إنترنت |

## الملفات

- `index.html`: التطبيق كله (واجهة ومنطق).
- `sw.js`: التخزين للعمل بدون إنترنت.
- `manifest.webmanifest` والأيقونات: للتثبيت على الشاشة الرئيسية.
